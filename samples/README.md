# Sample PDFs

This directory contains sample PDF files for testing the AutoPDF Orchestrator application.

## Files

- `sample-bookmarks.pdf` - A sample PDF with bookmarks (table of contents) for testing auto-split functionality

## Adding Samples

To add your own sample PDFs:

1. Place the PDF file in this directory
2. Update this README with a description
3. Use for manual testing of the application

## Testing

Sample PDFs are useful for:
- Testing auto-detection of bookmarks
- Testing manual page range splitting
- Testing summarization and keyword extraction
- Testing PDF export and ZIP creation
